# 🚗 카풀 기록

고정 멤버 4명(A, B, C, D)의 출퇴근 카풀에서 **날마다 누가 탔고 누가 운전했는지** 기록하고,
월별로 **운전자별·조합별 횟수**를 자동으로 세어 주는 웹 도구입니다.

**바로 쓰기:** https://uto617k-lang.github.io/carpool-tool/

## 주요 기능

- **일일 기록**: 날짜 → 참여자 체크 → 운전자 선택 → 저장. 카풀이 없던 날은 [카풀 없음].
- **달력**: 평일만 표시. 기록됨 / 카풀 없음 / 미입력 / 공휴일을 색으로 구분.
- **미입력 알림**: 기록이 빠진 평일 수를 보여주고, 가장 오래된 날로 바로 이동.
- **월별 통계**: 운전자별 운전·동승 횟수(운전이 가장 적은 사람 강조), "운전자 A + 동승자 B·C" 형식의 조합별 횟수.
- **엑셀 내보내기**: 전체 기록과 월별 통계를 `.xlsx`로 백업.
- **단축키**: `1`~`4` 참여자 체크, `Shift`+`1`~`4` 운전자 선택, `Ctrl`+`S` 저장, `←` `→` 이전/다음 평일.

## 데이터는 어디에 저장되나요?

기록은 이 웹페이지나 GitHub가 아니라 **내 PC의 CSV 파일 하나**에만 저장됩니다. 인터넷으로 전송되지 않습니다.

- 처음 한 번 [새 파일 만들기]로 `carpool_records.csv` 위치를 정합니다.
- 다음부터는 열 때 [파일 다시 연결] → "허용"만 누르면 됩니다.
- 저장할 때마다 파일을 먼저 다시 읽기 때문에, 다른 곳에서 바뀐 내용을 덮어쓰지 않습니다.
- CSV를 엑셀로 열어 둔 상태에서는 저장이 실패할 수 있습니다. 엑셀을 닫고 다시 저장하세요.

CSV 형식:

```csv
date,status,driver,passengers
2026-11-19,carpool,A,B;C
2026-11-20,none,,
```

## 사용 환경

- PC의 **Microsoft Edge** 또는 **Google Chrome** (파일 저장 기능 때문에 다른 브라우저는 지원하지 않음)
- 엑셀 내보내기는 인터넷 연결이 필요합니다 (SheetJS 라이브러리를 CDN에서 불러옴).

## 공휴일 갱신

공휴일은 달력 표시용이며 2026~2027년분이 들어 있습니다. 새 연도는 `index.html`의 `HOLIDAYS` 목록에
`'YYYY-MM-DD': '이름'` 형식으로 추가하세요. 공휴일 정보가 없는 연도를 보면 달력 위에 안내가 표시됩니다.
